# CHRIST'S WORLD · 使用说明

## 一、文件结构（已经按分类整理好）

```
Web/
├── index.html            ← 网站首页（个人介绍 + 分类入口），双击它打开网站
├── css/
│   └── style.css         ← 全站样式（颜色、字体、卡片、按钮都在这里改）
├── js/
│   └── common.js         ← 全站公共脚本（页脚年份、复制微信号、奖牌系统、获奖弹窗）
├── categories/
│   └── games.html        ← 「游戏」分类页（游戏卡片列表 + 右上角奖牌榜）
├── games/
│   ├── snake.html        ← 游戏 1：贪吃蛇（已完成，可直接玩）
│   ├── mario.html        ← 游戏 2：仿马里奥（开发中占位页，等你具体要求）
│   ├── tictactoe.html    ← 游戏 3：井字棋（玩家 vs 智能 AI，可选择先后手）
│   └── battlematch.html  ← 游戏 4：对战消消乐（消消乐攒分出兵，攻破敌方基地获胜）
├── assets/
│   └── avatar.jpg        ← 头像图片（想换头像直接用同名文件覆盖它，建议正方形图片）
└── tools/                ← 【仅本地，不上传】开发者工具
    ├── 启动平衡编辑器.bat  ← 双击启动数值后台（详见第五节）
    ├── balance_editor.py  ← 后台程序（零依赖，Python 直接运行）
    └── backup/            ← 后台每次保存前自动备份的 battlematch.html
```

## 二、怎么在本地预览

- 最简单：直接双击 `index.html`，用浏览器（Edge / Chrome）打开。
- 用 PyCharm：在 PyCharm 里打开 Web 文件夹，右键 `index.html` → Open in Browser。
- 模拟真实网站（推荐，和上线后效果一致）：在 Web 文件夹里打开终端，运行
  `python -m http.server 8000`，然后浏览器访问 `http://127.0.0.1:8000`。

## 三、改成你自己的信息（搜索文件里的 TODO 注释）

1. 网站名字：每个 HTML 顶部导航和页脚里的 `CHRIST'S WORLD`；浏览器标签标题统一为「你爹的网站」（搜 `<title>` 修改）。
2. 首页 `index.html`：大标题、联系方式、分类卡片标题，需要改的位置有 TODO 注释标注。
3. 换头像：把新图片命名为 `avatar.jpg`，放进 `assets/` 文件夹覆盖原文件即可（建议正方形）。
4. 改微信号：在 `index.html` 里搜索 `cqh1489113437`，一共两处（显示文字和“复制微信号”按钮），一起替换成新号码。
5. 改配色：打开 `css/style.css`，最上面 `:root` 里的颜色变量，改完全站自动生效。
6. 不想要「学习笔记 / 实用小工具」两张占位分类卡：在 index.html 里整段删除即可。

## 四、怎么添加新游戏

1. 复制 `games/` 里任意一个游戏 html（例如复制 snake.html），改名成新游戏（如 `games/tetris.html`），替换里面的游戏内容。
2. 打开 `categories/games.html`，复制任意一张 `<a class="pixel-card">…</a>` 卡片，
   改链接、标题、简介和封面图（文件里有现成的模板注释）。
3. 卡片网格：3 张时一行 3 个；现在是 4 张，games.html 里用的是 `<div class="card-grid four">`（桌面一行 4 个、平板 2 列、手机 1 列）；想加第 5 张时把 `four` 去掉即回到自适应换行。

## 五、游戏玩法与可调参数

**贪吃蛇（snake.html）**
- 方向键 / WASD 移动，空格暂停；手机打开会自动出现触屏方向键。
- 最高分会自动保存在浏览器里（localStorage，不上传任何数据）。
- 1-5 级地图上只有 1 个果子；**升到 6 级起同时存在 2 个果子**，吃掉后立刻补足。
- 难度在 `games/snake.html` 顶部 JS 注释处调：初始速度、最快速度、升级所需果子数；双果子门槛搜 `level >= 6`。

**井字棋（tictactoe.html）**
- 进入后先选「我先手（X）」或「AI 先手（我执 O）」。
- AI 使用 minimax（极小极大）算法推演完整博弈树，正常走法不会输；**但每次落子有 5% 概率主动失误**（不按最优位置、随机下到其他空位），抓住失误才能赢它（失误率搜 `Math.random() < 0.05` 修改）。
- 你与 AI 的总比分自动保存在浏览器，「清空比分」按钮可归零；同等最优走法 AI 会随机选择，每局开局不同。

**对战消消乐（battlematch.html）**
- 右侧是 8×8 消消乐：点一个方块再点相邻方块交换，横 / 竖凑成 3 个以上同色即可消除；没有凑成会自动换回。
- 计分（当前设置，可在后台改）：三连 10 分、四连 15 分、五连及以上 25 分；一次交换同时消出多组，每组都计分；
  消除后新方块落下又自动凑成消除算「连锁」，第 2 波得分 ×1.5、第 3 波 ×2、第 4 波 ×2.5，依此类推。
- SCORE 是总得分（只增不减）；消除同时获得**能量**（1 分 = 1 能量，当前上限 1000），买兵只花能量，免费刀兵不扣能量。
- **每累计 20 分（按 SCORE 计算、可在后台改）自动从蓝色我方基地派出 1 名刀兵**（免费、均衡近战）。
- 购买条下方是长能量条，右端显示「当前 / 上限」；购买条可花能量买兵，当前价格：长矛手 80（长柄近战、攻高血薄）、
  弓箭手 100（远程射箭）、法师 160（远程法弹、范围伤害）、投石车 350（超远程投石、范围伤害、血厚走得慢）；
  四个兵种按钮右上角分别标着 **1 / 2 / 3 / 4**，按键盘数字键即可快速购买；能量不够会弹出提示。
- 顶部计分栏右侧三个按钮，从左到右：**暂停 ｜ 重置 R ｜ 重新开始**（三个按钮同尺寸，手机上同样可点）。
  - **空格键**或点「暂停」：暂停 / 继续（弹出遮罩，棋盘和战场全部冻结，点棋盘无效）。
  - 点「重新开始」会先弹确认框提示「当前对局的得分、能量和战场都会清空」，点「是，重新开始」才重开；
    点「否，继续游戏」或按 **Esc** 回到游戏，按**回车**等同点「是」，防止误触清空对局。
- **找不到能消的方块时**：点顶部「重置 R」按钮，或按键盘 **R 键**——旧方块碎成 4 块碎片向下坠落消失，
  新方块从屏幕顶部逐列掉落，全程约 **3 秒**不能操作（惩罚），新棋盘保证没有现成三连。
- 左侧竖向战场：蓝色我方基地在最下方、红色敌方基地在最上方（基地已压扁，对战区域更长）；
  红色敌军随时间变强、出兵变快（约 12 秒准备期后开始出兵）。
- **自动寻路**：每个士兵会搜索自身附近（当前为方圆 **120 像素**、可在后台改）最近的敌军（含敌方哨兵塔），
  自动斜向走过去开打；目标死亡或离开警戒范围才换目标，否则继续向基地推进；同方士兵会二维避让、不重叠。
- **哨兵塔**：双方半场靠近基地约 1/3 处的左右两边各有 1 座（全场共 4 座），自动射箭攻击进入射程的敌方小兵，
  也会被小兵打爆（废墟不挡中路，胜负仍只看基地）。
- 双方基地当前各 2000 血（可在后台改），**打破红色基地即胜利，蓝色基地被打破则失败**，结算后可「再来一局」。
- **战场尺寸：宽 300 × 高 650 像素**（canvas 内部分辨率，也是电脑端显示尺寸；手机端等比缩小）。想改大小必须同步 4 处：
  ① JS 里 `var FW = 300, FH = 650;`；② HTML 里 `<canvas id="fieldCanvas" width="300" height="650">`；
  ③ CSS 里 `#fieldCanvas { width: 300px; height: 650px; }`；④ 移动端媒体查询里 `aspect-ratio: 300 / 650;`。
  基地大小与位置（`BASE_W` / `BASE_H` / `BASE_Y` / `STOP_Y` / `SPAWN_Y`）和塔位置（`TOWER_INSET = FH / 6`、`TOWER_X`）都会自动跟随 FH / FW。
- **平衡数值后台（开发者专用，玩家在网页上看不到、改不了）**：双击 `tools/启动平衡编辑器.bat`
  （或运行 `python tools/balance_editor.py`），自动打开后台网页 `http://127.0.0.1:8765`，可改：能量上限、
  免费出兵间隔、寻路范围、基地血量、三 / 四 / 五连得分、哨兵塔血量 / 伤害 / 射程 / 攻速、五种兵的花费 / 血量 /
  伤害 / 攻击距离 / 攻速 / 移速（远程兵还有弹速 / 溅射半径）。
  - 点「保存到源代码」会**直接改写 battlematch.html 里的 `CFG0` 默认值**，游戏页按 F5 即生效，提交推送后对所有玩家生效；
    每次保存前自动把旧文件备份到 `tools/backup/`（带时间戳，改错了从备份复制回来即可）。
  - 「重新读取」放弃未保存的修改；「恢复出厂数值」填回初始值（仍需再点一次保存才会写文件）；「打开游戏」在新标签预览。
  - 后台只监听 127.0.0.1（仅本机能访问），关掉命令行黑窗口即停止；`tools/` 已写入 `.gitignore`，**不会上传 GitHub、不会部署**。
- 源代码数值位置：默认数值集中在 JS 的 `var CFG0`（后台改的就是它）；外观半径 / 弹道颜色在 `UNITS`，
  敌方出兵节奏在 `enemyPick` / `enemyTimer`；计分常量搜 `SCORE3`。
- 本游戏暂未接入奖牌系统，奖牌规则等你定。

**奖牌系统（游戏分类页右上角奖牌榜）**
- 奖牌数据保存在浏览器 localStorage（key 为 `site-medals`），每个游戏只保留已解锁的奖牌，重复达到不重复弹窗。
- 贪吃蛇：单局得分达到 100 解锁铜牌、200 银牌、300 金牌（结算时按本局得分一次性判定）。
- 井字棋：累计平局 1 次解锁铜牌、累计获胜 1 次解锁银牌、累计获胜 5 次解锁金牌（按累计总比分判定，清空比分不会收回已得奖牌）。
- 新解锁奖牌时弹出像素风提示框，点「确认」（或按回车 / Esc）关闭；奖牌榜金 / 银 / 铜数量为所有游戏之和。
- 游戏列表页每张游戏卡片标题右侧会显示该游戏**已获得的最高等级奖牌**小图标，没获得任何奖牌时不显示。
- 想调阈值：贪吃蛇搜 `score >= 100`、井字棋搜 `scores.draw >= 1`；想清空奖牌在浏览器控制台执行 `localStorage.removeItem('site-medals')` 后刷新。

## 六、以后上线（网站全部改好之后）

1. 把整个 Web 文件夹上传到 Gitee Pages（国内快）或 Vercel / GitHub Pages（免费），
   平台会给一个免费网址，先发给朋友测试。
2. 测试没问题再买域名，在域名后台加解析、在托管平台绑定域名即可。
3. 用 Vercel / Gitee Pages 这类静态托管不需要备案；买国内云服务器才需要备案。
